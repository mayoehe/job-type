Servers are down? Start them ⬇

Option A — single server (recommended): serves the built UI + API on one port. Needs JDK 17+ (no Node, no Maven). Keep one terminal open, then press Recheck.

cd /d "%USERPROFILE%\OneDrive\Documents\GitHub\job-type\backend-java"
.\run.bat

Then open http://localhost:8787

Option B — dev mode (two terminals): live-reload frontend + backend separately.

1 — Backend (Java):

cd /d "%USERPROFILE%\OneDrive\Documents\GitHub\job-type\backend-java"
.\run.bat

2 — Frontend:

cd /d "%USERPROFILE%\OneDrive\Documents\GitHub\job-type\frontend"
npm install
npm run dev

Then open http://localhost:5173 (proxies /api → backend).

If the single-port UI looks stale, rebuild it: cd frontend, npm run build, then restart the backend (.\run.bat again).

To verify the backend: cd backend-java, java -cp out com.jobshield.RegressionTest (8/8 checks).
